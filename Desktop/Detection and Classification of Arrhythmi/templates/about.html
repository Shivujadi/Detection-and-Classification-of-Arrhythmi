About Project & Problem Statement

Cardiac arrhythmia refers to an irregular heartbeat sequence resulting from electrical conduction defects in the heart muscle. Arrhythmias range from harmless premature contractions to severe life-threatening conditions such as Ventricular Tachycardia and Fibrillation.

Electrocardiograms (ECG) are the non-invasive gold standard diagnostic tool for monitoring cardiac electrical activity. Manually analyzing long continuous 24-hour Holter monitor ECG recordings is time-consuming and prone to human error. This project implements a machine learning system to automate heartbeat classification.

MIT-BIH Arrhythmia Database

The primary dataset used is the PhysioNet MIT-BIH Arrhythmia Database containing 48 fully annotated half-hour two-channel ambulatory ECG recordings sampled at 360 Hz from 47 human subjects.

  • Total Records: 48 WFDB Records (100–234)
  • Sampling Rate: 360 Hz
  • Primary ECG Lead: Modified Lead II (MLII)
  • Total Inspected Annotations: 112,647 annotations
  • Segmented Heartbeat Window: 180 sample points around R-peaks

AAMI EC57 5-Class Standard

Heartbeats are categorized according to the standard Association for the Advancement of Medical Instrumentation (AAMI EC57) guidelines:

AAMI Class Description MIT-BIH Raw Symbols
N Normal / Bundle Branch Block N, L, R, e, j
S Supraventricular Ectopic (SVEB) A, a, J, S
V Ventricular Ectopic (VEB) V, E
F Fusion Beat F
Q Paced / Unclassifiable Beat /, f, Q

Machine Learning Algorithms Implemented

1. Logistic Regression

Multinomial linear classification with L-BFGS optimization.

2. KNN & Weighted KNN

$k=5$ nearest neighbors with distance-weighted voting.

3. Random Forest

Ensemble of 100 decision trees for robust non-linear boundaries.

4. Naive Bayes & SVM

Gaussian Naive Bayes and Calibrated Linear SGD-SVM.
